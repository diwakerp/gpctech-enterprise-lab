# GPCTech Enterprise Infrastructure Lab

## Overview

This project documents the design, deployment and management of a simulated enterprise IT infrastructure environment.

The lab demonstrates practical experience with Windows Server administration, Active Directory, virtualization, networking, remote management and secure remote access.

## Objectives

- Build enterprise-style on-premises infrastructure
- Deploy centralized identity management
- Implement file and print services
- Configure secure remote administration
- Document infrastructure operations
- Create a foundation for security monitoring and automation

## Technologies

- Windows Server 2019 and 2022
- Hyper-V
- Active Directory Domain Services
- DNS
- DHCP
- File Services
- Print Services
- UniFi Networking
- NetLock RMM
- Cloudflare Zero Trust
